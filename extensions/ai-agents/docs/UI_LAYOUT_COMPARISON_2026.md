# Before / 目標 / After（2026-10-28）

比較画像は [ui-layout-2026/index.html](ui-layout-2026/index.html)。390px Dark 日本語が基準。300px と 600px の Home / Chat、Light / High Contrast の代表は `ui-layout-2026/after` と `ui-layout-2026/themes` にある。

Cursor 列は計測した画面ではない。[CURSOR_LAYOUT_MEASURE_2026.md](CURSOR_LAYOUT_MEASURE_2026.md) の設計目標である。

## Chat

- Before: ユーザー発話が会話幅いっぱいの帯。回答は地の文。
- 目標: 発話は内容幅で右、回答は地の文。
- After: 「READMEの誤字を直して」が右の塊になり、添付チップもその中に入る。回答、見出し、リスト、コードはその下で左から読める。
- 残る差: 発話が長いと 88% まで広がり、全幅に近く見える。コピーは回答側にあり、発話のホバー操作は付けていない。編集は発話のクリックのまま。
- 理由: 短い依頼と長い回答を、幅で区別するため。

## Home

- Before: 新規チャットは見出し幅のボタン。履歴は名前の下に時刻が寄りやすい。
- 目標: 新規を最上段の主操作にし、履歴は 1 行。
- After: 新規チャットがサイドバー幅の主ボタンになる。選択中の行は左の線と選択背景。名前と時刻が同じ行。
- 残る差: 実行中の行は、状態の文字が時刻の左に並ぶ。件数が多いときの検索はない。
- 理由: 狭いサイドバーでは、最初に押す操作を列の幅いっぱいにした方が見失いにくい。

## 実行中の Tool

- Before: 作業ログが回答の前にフラットに並ぶ。
- 目標: 思考、ツール、差分は回答の上の作業。完了後は 1 行。失敗は隠さない。
- After: 実行中はタイトル横に点。ログは開いたまま、Read は 1 行、ターミナルはコマンド面。完了後の Chat では「作業時間」の 1 行に戻る。失敗ツールはログを閉じても `.tool-failures` に理由を出す。
- 残る差: ログを開くと、シェルのコマンド行は展開前から見える。これは既存テストがコマンドカードの中身を要求しているため。
- 理由: 進行中だけ詳細を出し、終わったターンは文章を先に読ませる。

## Plan

- Before: 「計画を表示」が文字リンクに近く、Build が右の主ボタン。
- 目標: 完成した計画では View Plan を副、Build を主にする。失敗は Build を主に見せない。
- After: View Plan が副ボタン、Build が主ボタンで、同じ行の右に寄る。モデル選択は展開時に Build の隣。`canBuild` が偽で error または unknown のときは `.is-blocked` で副ボタン色になり、エラーをカード先頭に出す。
- 残る差: 折りたたみ中の計画にはモデル選択を出さない。既存の `showBuildModel` の条件を変えていない。
- 理由: 次に押すボタンを、本文を読み終わった位置に置く。

## Composer とモデルメニュー

- Before: 入力の下に Mode、長いモデル名、添付、送信が 1 行。300px では行が折り返せた。
- 目標: 1 行のまま、狭い幅では名前を省略する。
- After: 390px では長いモデル名が残り、300px では `GPT-6.1 ...` まで省略して添付と送信が同じ行に残る。メニューは入力の直上に開く。実 VS Code の空チャットでは入力高さが 34px で、「レイアウト確認」が入った。
- 残る差: 実 Host はプロバイダの shell が来るまで Mode が「Select ...」になる。Capability が無い操作は出さない既存動作。
- 理由: 折り返すと送信が次の行に落ち、視線が縦に増える。

## Approval、Diff、Subagent

- Approval: 末尾のカード。左の警告線、許可、セッション許可、拒否。選択肢は変えていない。発話は右寄せのまま。
- Diff: ファイル名、増減、展開後のプレビュー、VS Code の Diff へ開く導線は既存の行のまま。変更バーは件数と Review。
- Subagent: ドックの実行中一覧と、ターン内の行。ヘッダーのターミナルボタンは外し、Composer 上のターミナル一覧だけにした。
- 残る差: サブエージェント詳細は従来の縦スタック。今回の主変更は会話の列である。

## 幅

300px の Chat ではタイトルだけ省略され、戻る、新規、設定、送信は残る。600px ではガターが広がり、発話の最大幅は 34em で頭打ちになる。
